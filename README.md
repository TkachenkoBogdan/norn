# Norn

The download page for **Norn** (formerly Claude Spend Bar), a macOS menu-bar
readout of your Claude usage.

**<https://tkachenkobogdan.github.io/norn/>**

This repository holds the page and nothing else. The app is released from
[TkachenkoBogdan/homebrew-tap](https://github.com/TkachenkoBogdan/homebrew-tap/releases),
which is also the Homebrew tap:

```
brew install --cask tkachenkobogdan/tap/norn
```
