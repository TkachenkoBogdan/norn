What you get when you click it

A panel under the menu bar. Nothing else — no window, no Dock icon. Which of the two you see depends on how your Claude account is billed.

Every Claude Code session, priced

The sessions on this Mac, from the terminal and the desktop app, with what each one cost, using Claude Code's own totals wherever it records them.

  • See where the money went. Each session with its last activity and cost, and a dot on the ones working right now.
  • Desktop, CLI, Runs. Toggle each on or off in any mix, and sort by recent, cost or name. It remembers.
  • Eval runs sit under the session that started them. A batch of claude -p runs reads as one line, not forty.
  • Each account keeps its own. Switch organisation and the list shows only the sessions billed to it.

As wide as you want it

On a MacBook with a notch, a long reading pushes other icons out of sight. Pick how much room it takes in Settings, under Menu bar.

  • From full to just the mark. $478.20 / $1000, $478 / 1k, $478, or the mark alone.
  • Subscriptions too. 42% · 18% with the weekly, 42%, 42, or the mark.
  • Changes as you pick. The bar is the preview, and the choice is kept.
  • Problems still show. Even as a mark alone, a missing key or an error still gets its sign.

Installing

Two ways in. They install the same app — pick whichever you are comfortable with. Either way it keeps itself up to date: new versions download in the background and install while the panel is closed.

Disk image

No terminal needed.

  1. Open the downloaded Norn.dmg.
  2. Drag Norn onto the Applications folder in the same window.
  3. Open your Applications folder and double-click Norn.

Nothing to download again — the app updates itself.

Homebrew

If you already use brew.

brew install --cask tkachenkobogdan/tap/norn

On 1.4.3 or earlier? Upgrade once by hand; from 1.5.0 on it updates itself:

brew upgrade --cask norn

Homebrew installs it but does not start it. To open it the first time:

  1. Open your Applications folder in Finder.
  2. Double-click Norn.

Or from the same terminal:

open -a Norn

Spotlight will not find it until macOS has indexed it, so use Finder or the command above rather than ⌘Space.

Nothing appears in the Dock — look for the ball in the menu bar, at the top right of your screen. The app adds itself to your login items the first time it runs, so it is there after a restart. You can turn that off in its settings.

Connecting your Claude account

The app reads your usage through your own Claude Code, which already knows your plan and limits. It never asks for, stores or sends a login.

  1. Install the Claude Code CLI, or the Claude app, which carries its own copy.
  2. Sign in to Claude Code once, in Terminal: claude auth login.
  3. Click the ball in the menu bar and press Connect.

Not signed in yet? The panel shows the exact command, and Open Terminal types it for you to run. Coming from 1.x: your old session key is deleted from the Keychain on first launch.

Unofficial, and built on undocumented output

This app is not made by, endorsed by, or affiliated with Anthropic. It reads the usage report Claude Code's /usage command prints. That output is not a published API: it carries no compatibility promise and can change or disappear in any Claude Code release, without notice.

When that happens the app stops showing a reading until it is updated. Treat the numbers as a convenience, not as a billing record — the usage page in claude.ai remains the authority.

It reads only your own accounts, through the claude you installed, never holds a login, and never writes anything back.
